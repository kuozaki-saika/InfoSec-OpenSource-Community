# 风险评估记录 — 靶场认证系统

## 模块概述
为 upload-labs 靶场新增用户注册/登录/登出认证系统，使用 PHP Session + JSON 文件存储用户数据。

## 识别的安全风险

| # | 风险 | 威胁描述 | 严重程度 |
|---|------|----------|----------|
| 1 | 密码泄露 | 用户密码以明文或弱哈希形式存储，库泄露导致凭据外泄 | 高 |
| 2 | 会话固定 | 攻击者诱导用户使用已知 session ID 登录后劫持会话 | 高 |
| 3 | 暴力破解 | 无限尝试登录，遍历密码 | 中 |
| 4 | XSS | 用户名/错误信息未转义直接输出 | 中 |
| 5 | 用户名枚举 | 通过注册/登录页面的不同错误信息推断已存在用户 | 低 |
| 6 | 输入注入 | 用户名包含特殊字符破坏 JSON 存储 | 中 |

## 风险处置策略

| 风险 | 处置 | 实现方式 |
|------|------|----------|
| 密码泄露 | 消除 |  |
| 会话固定 | 消除 |  登录后立即轮换 |
| 暴力破解 | 缓解 | 用户名密码统一错误提示，不区分 |
| XSS | 消除 |  所有输出 |
| 用户名枚举 | 缓解 | 注册/登录使用统一错误信息 |
| 输入注入 | 消除 | 用户名正则白名单 ，长度 3-32 |
