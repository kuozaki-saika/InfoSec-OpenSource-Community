# 项目约束文档 — 靶场认证系统

> 每次与 AI 开始新对话时粘贴此约束。

## 背景
为现有 PHP upload-labs 靶场添加用户注册/登录/登出功能，靶场本身无数据库，使用 JSON 文件存储。

## 安全约束（必须遵守）

1. **密码存储**：使用 ，禁止 /
2. **会话安全**：登录成功后调用 ，登出时 
3. **输入校验**：用户名仅允许 ，长度 3-32；密码最少 6 位
4. **输出编码**：所有用户输入回显使用 
5. **错误统一**：登录失败不区分用户名不存在/密码错误

## 禁止行为

- 禁止密码明文存储
- 禁止 echo 未转义的用户输入
- 禁止 session ID 放入 URL
- 禁止使用 eval/assert 处理用户输入

## 技术栈
PHP 原生，无框架，JSON 文件存储，bcrypt。
