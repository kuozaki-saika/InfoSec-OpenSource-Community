# 安全自查清单 — 靶场认证系统

- [x] 用户名正则白名单 
- [x] 用户名长度 3-32
- [x] 密码长度 ≥ 6

- [x] 登出时  销毁

- [x] 所有用户输入回显使用 
- [x] 错误信息不暴露内部细节
