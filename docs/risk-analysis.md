# 风险分析记录

## 模块概述
为现有文档图像去噪系统（Python CLI 脚本）新增 Flask Web API 接口，提供 HTTP 文件上传去噪服务。

## 识别的安全风险

| # | 风险 | 威胁描述 | 严重程度 |
|---|------|----------|----------|
| 1 | 任意文件上传 | 攻击者上传恶意文件（webshell、可执行脚本）到服务器 | 高 |
| 2 | 路径穿越 | 通过 `../` 等特殊文件名访问/覆盖系统文件 | 高 |
| 3 | DoS — 大文件 | 上传超大文件耗尽服务器内存和磁盘 | 中 |
| 4 | DoS — 高频请求 | 短时间内大量请求占满计算资源 | 中 |
| 5 | 信息泄露 | 错误响应暴露服务器内部路径或堆栈信息 | 低 |
| 6 | 恶意图像文件 | 构造畸形图像触发 OpenCV 解析漏洞 | 中 |

## 风险处置策略

| 风险 | 处置 | 实现方式 |
|------|------|----------|
| 任意文件上传 | 消除 | 扩展名白名单 + MIME 二次校验 |
| 路径穿越 | 消除 | werkzeug `secure_filename` + UUID 重命名 |
| DoS 大文件 | 缓解 | Flask `MAX_CONTENT_LENGTH` 限制 16MB |
| DoS 高频 | 缓解 | IP 级别频率限制（20次/分钟） |
| 信息泄露 | 消除 | 统一错误响应格式，不暴露内部路径 |
| 恶意图像 | 缓解 | `cv2.imread` 返回 None 时拒绝处理 |
