# 项目约束文档

> 每次与 AI 开始新对话时粘贴此约束。

## 背景
为已有的 Python 文档图像去噪系统（Random Forest + OpenCV）添加 Web API 接口。

## 安全约束（必须遵守）

1. **文件类型白名单**：只接受 png, jpg, jpeg, bmp, tiff, tif 格式上传
2. **文件大小上限**：不超过 16MB
3. **路径安全**：所有文件名使用 `werkzeug.utils.secure_filename` 处理，禁止直接使用用户输入的文件名拼接路径
4. **频率限制**：每 IP 每分钟不超过 20 次请求
5. **错误信息安全**：错误响应不包含服务器路径、堆栈跟踪或内部状态
6. **无动态代码执行**：不接受、不执行任何用户提交的代码

## 禁止行为

- 禁止使用 `os.system` / `subprocess` 调用用户提供的路径或文件名
- 禁止在响应中回显完整文件路径
- 禁止使用 `pickle.load` 加载用户上传的数据
- 禁止设置 `debug=True` 在生产环境

## 约束来源
- OWASP 文件上传防护指南
- Flask 安全最佳实践
