## 整改措施

### 问题1：会话销毁不完整
- **改了什么**：logout.php 增加 
- **改完条件**：登出后无法通过旧 session 访问受保护页面

### 问题2：无访问控制
- **改了什么**：head.php 新增  调用，未登录用户所有靶场页面自动跳转 login.php
- **改完条件**：直接访问任何 Pass-XX/index.php 均重定向至登录页
