## 2. 业务逻辑约束

### 2.1 密码重置流程约束

```
用户发起重置 → 密保问题验证（≥2个正确）→ 获取重置令牌 → 
二次身份确认（验证码）→ 新密码策略检查 → 密码历史检查 → 重置成功
```

- 重置令牌有效期 5 分钟
- 验证码为 6 位数字
- 新密码不能与历史密码相同
- 重置成功后自动解除账户锁定

### 2.2 登录安全约束

```
用户登录 → 检查账户锁定 → 验证密码 → 
成功: 重置尝试计数 | 失败: 递增计数 + 冷却延时
```

- 5 次失败后锁定 15 分钟
- 每次失败后 2 秒冷却延时
- 不存在用户时返回相同错误消息（防枚举）

### 2.3 安全扫描约束

- 不扫描虚拟环境 (.venv)
- 不扫描缓存目录 (__pycache__)
- 不扫描数据目录 (data, Dataset)
- 不扫描预训练模型目录 (pretrained_models)
- 排除注释行中的危险函数匹配

## 3. 安全设计约束

### 3.1 加密约束

| 项目 | 算法 | 参数 |
|:---|:---|:---|
| 密码哈希 | SHA-256 (PBKDF2 风格) | 100,000 次迭代 + 32字节盐值 |
| 密保答案哈希 | SHA-256 | 独立盐值 + 100,000 次迭代 |
| 重置令牌 | secrets.token_urlsafe | 32 字节随机 |
| 验证码 | secrets.choice | 6 位数字 |

### 3.2 安全流程约束

- 所有用户输入需经过验证和清理
- 敏感操作需要二次身份确认
- 密码重置必须验证密保问题
- 账户锁定后需管理员解锁或等待超时
- 防止用户名枚举攻击（统一错误消息 + 统一延时）
