# ✅ 项目安全检查清单 (Security Checklist)

## 项目信息

- **项目名称**：基于神经网络的图像分类实验
- **负责人**：陈相宇
- **检查日期**：2026-06-30
- **检查版本**：v1.0

## A. 认证与授权 (Authentication & Authorization)

- [x] **A-01**：密码使用安全哈希算法存储（SHA-256 + 盐值 + 100K迭代）
- [x] **A-02**：每个用户使用独立的密码盐值
- [x] **A-03**：密码强度策略已强制执行（长度 + 字符多样性）
- [x] **A-04**：登录尝试限制已实施（5次失败锁定15分钟）
- [x] **A-05**：登录失败冷却延时已启用（2秒/次）
- [x] **A-06**：用户注册时需设置密保问题（≥3个）
- [x] **A-07**：密码重置需通过密保验证 + 二次身份确认
- [x] **A-08**：重置令牌有过期时间（5分钟）
- [x] **A-09**：防止用户名枚举攻击（统一错误消息 + 统一延时）
- [x] **A-10**：密码历史记录已保留（最近5个，防止重用）

## B. 数据保护 (Data Protection)

- [x] **B-01**：密保答案以哈希形式存储（独立盐值）
- [x] **B-02**：敏感数据不在日志中输出（密码/令牌仅模拟显示）
- [x] **B-03**：用户数据存储使用 JSON 格式，含版本信息
- [ ] **B-04**：训练数据集应进行脱敏处理
- [x] **B-05**：用户凭证文件应有适当的文件权限

## C. 输入验证 (Input Validation)

- [x] **C-01**：用户名格式已验证（3-32字符，字母/数字/下划线）
- [x] **C-02**：密码长度已验证（8-128字符）
- [x] **C-03**：密保答案非空检查
- [ ] **C-04**：模型输入数据应进行范围验证
- [x] **C-05**：代码扫描中排除注释行的误报

## D. 会话与令牌管理 (Session & Token Management)

- [x] **D-01**：密码重置令牌使用安全随机数生成
- [x] **D-02**：令牌有过期时间限制
- [x] **D-03**：二次身份验证码为6位数字随机码
- [x] **D-04**：验证码使用后即时清理
- [ ] **D-05**：建议增加操作会话超时机制

## E. 错误处理与日志 (Error Handling & Logging)

- [x] **E-01**：关键操作有明确的成功/失败反馈
- [x] **E-02**：安全事件有记录（登录失败、账户锁定、密码重置）
- [ ] **E-03**：建议增加结构化日志（JSON格式）便于审计
- [x] **E-04**：文件读写错误有异常处理

## F. 代码安全 (Code Security)

- [x] **F-01**：已实现安全扫描工具检测危险函数
- [x] **F-02**：已实施硬编码密钥扫描
- [ ] **F-03**：建议对 eval/exec 等函数进行彻底排查
- [x] **F-04**：关键安全函数有详细的中文注释
- [x] **F-05**：文件权限检查已集成

## G. 依赖安全 (Dependency Security)

- [x] **G-02**：已知 CVE 漏洞已标注
- [ ] **G-03**：建议使用 `pip-audit` 进行持续依赖监控
